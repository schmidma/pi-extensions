# Copy code

[Install from the checkout](../../README.md) using package name `copy-code`.

In interactive Pi, `/copy-code` opens a menu of code blocks from the latest
assistant text response. `Ctrl+Alt+C` opens the same menu.

`/copy-code all` lists code blocks from assistant responses on the current branch,
newest response first.

Use `Up`/`Down` to choose a block, `Enter` to copy it, or `Esc` to cancel.
Only the selected code contents are copied, without Markdown fences.

No configuration.
